# utils

Internal package in the [Badman](../../README.md) Turborepo monorepo. Import as `@badman/utils`.

## Building

```bash
pnpm turbo run build --filter=@badman/utils
```

## Running unit tests

Unit tests run on [Jest](https://jestjs.io):

```bash
pnpm turbo run test --filter=@badman/utils
```
