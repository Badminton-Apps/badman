# backend-notifications

Internal package in the [Badman](../../README.md) Turborepo monorepo. Import as `@badman/backend-notifications`.

## Building

```bash
pnpm turbo run build --filter=@badman/backend-notifications
```

## Running unit tests

Unit tests run on [Jest](https://jestjs.io):

```bash
pnpm turbo run test --filter=@badman/backend-notifications
```
