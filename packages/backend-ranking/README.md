# backend-ranking

Internal package in the [Badman](../../README.md) Turborepo monorepo. Import as `@badman/backend-ranking`.

## Building

```bash
pnpm turbo run build --filter=@badman/backend-ranking
```

## Running unit tests

Unit tests run on [Jest](https://jestjs.io):

```bash
pnpm turbo run test --filter=@badman/backend-ranking
```
