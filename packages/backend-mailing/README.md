# backend-mailing

Internal package in the [Badman](../../README.md) Turborepo monorepo. Import as `@badman/backend-mailing`.

## Building

```bash
pnpm turbo run build --filter=@badman/backend-mailing
```

## Running unit tests

Unit tests run on [Jest](https://jestjs.io):

```bash
pnpm turbo run test --filter=@badman/backend-mailing
```
