Internal package in the [Badman](../../../../README.md) Turborepo monorepo. Import as `@badman/belgium-flanders-games`.

## Building

```bash
pnpm turbo run build --filter=@badman/belgium-flanders-games
```

## Running unit tests

```bash
pnpm turbo run test --filter=@badman/belgium-flanders-games
```
